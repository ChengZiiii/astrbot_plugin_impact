# astrbot_plugin_impact

基于 https://github.com/Special-Week/nonebot_plugin_impact 移植，并在 `0.2.0` 扩展为“全局长度共享、群内周玩法独立”的 AstrBot 群聊互动小游戏。

## 核心语义

- 用户长度仍然是全局共享的一份数据。
- 群排行、周统计、周报、荣誉墙都只基于当前群参与过玩法的成员。
- 周结算仍保留懒结算兜底：跨到新自然周后，本群第一次命中相关命令时会补结算上一周。
- 插件会在每周一指定时间尝试主动播报上一周完整周报；默认是周一上午 10:00，播报目标依赖该群曾有命令触发并记录过会话来源。

## 排行说明

- 群聊里 `jj排行榜` 显示当前群参与成员的群内排行，并附带你的全局排名。
- 私聊里 `jj排行榜` 不看群数据，只返回你的全局长度与全局排名。

## 周玩法说明

- 周 key 使用服务器本地时间下的 ISO 自然周，格式 `YYYY-Www`。
- 所有群聊玩法都会把发送者登记进当前群参与关系；有 `@` 目标时也会同步登记目标。
- `打胶`、`嗦牛子`、`查询`、`注入查询`、`pk`、`淫趴` 在群聊里都会写入当前周统计，并刷新本群主动播报所需的会话来源。
- `pk` 会累计连胜、连败与复仇目标。
- 同一周同一群内两人 `pk` 次数达到阈值后会被判定为宿敌。
- `本周周报` / `周报` 返回当前周实时汇总。
- `上周周报` 返回最近一次已结算的上周周报。
- 周报中显示的用户名优先使用群名片（card），其次为群昵称（nickname），最后回退到 QQ 号。已结算的上周周报会保留结算时的名字快照，不受后续改名影响。
- 旧别名（`jj排行榜` / `周榜` / `恩怨` / `荣誉墙` 等）仍然兼容可用，但帮助文案中只展示规范命名。

## 主要配置项

- `rank_min_users`: 排行榜最少人数
- `weekly_broadcast_hour`: 周一主动播报上周周报的小时
- `weekly_broadcast_minute`: 周一主动播报上周周报的分钟
- `rank_top_count`: 排行榜前列人数
- `rank_bottom_count`: 排行榜后列人数
- `weekly_rival_threshold`: 宿敌触发阈值
- `honor_wall_weeks`: 荣誉墙展示周数
- `weekly_top_n`: 周榜默认保留名次
- `commands_enabled`: 可按命令组启用/禁用旧命令与周玩法命令
- `rank_image_enabled`: 关闭后排行榜走纯文本
- `usage_image_enabled`: 关闭后帮助走纯文本
